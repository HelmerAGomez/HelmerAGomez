# Hi, i'm Helmer

Initially, I saw it as just a silly cat puzzle game, but the problem-solving aspects hooked me and profoundly impacted me. When graduation came around, I knew exactly what career to pursue.

The application we created was named [Focus Garden](https://github.com/HelmerAGomez/Focus-Garden.git). I worked on the frontend and backend of our application and found the experience to be exciting. I look forward to creating more full stack applications.
