# Hi, i'm Helmer

Initially, I saw it as just a silly cat puzzle game, but the problem-solving aspects hooked me and profoundly impacted me. When graduation came around, I knew exactly what career to pursue.

I look forward to bringing that same problem-solving mindset to helping others resolve their technical issues.
